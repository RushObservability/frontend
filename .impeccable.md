# Design context

Confirmed by the creator on 2026-09-12.

- Audience: engineers and SREs investigating production performance.
- Profiling jobs: find CPU hotspots, inspect call stacks, and compare releases or time windows.
- Tone: compact, practical, and consistent with Rush's Explore workspace.
- Keep existing typography, semantic colors, and the shared DataTable component.
- No gradients. No invented telemetry or decorative charts.
- Profiles belongs under Observe and remains a free, built-in capability.
- Profiles uses a full-width flame graph with the function table below it, including on wide screens.
